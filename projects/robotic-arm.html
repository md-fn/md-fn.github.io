Overview

Designed entirely from scratch in Fusion 360, 3D-printed, and assembled as a color-sorting robot for my Embedded Systems course.The color sensor reads the color of the objects, the arm picks up objects from the pickup area, and drop them in the correct bin, the bin positions are pre configured — using a PIC18, three 28BYJ-48 steppers ,9g servo, and a TCS3200 sensor.

Every mechanical decision was driven by real constraints: single-flange bearings were usedto keep joints compact and smooth, a herringbone gear at the base so there is minimum backlash, and passive 4-bar linkages so the end-effector stays parallel to the ground without an additional axis.

Mechanical Design

The arm has four key mechanical subsystems. Each was designed to solve a specific constraint rather than following a standard approach.

Base Rotation Herringbone 2:1 gear pair — eliminates axial backlash without pre-load, critical for a printed gear running under step-hold torque.
Joint Bearings Single-flange bearings at each pivot. One bearing per joint keeps the design compact while giving smooth, stable rotation with no rattle.
4-Bar Linkages Parallel 4-bar system passively keeps the end-effector horizontal at any arm angle — eliminates the need for a powered wrist DOF.
Gripper Parallel servo gripper — both fingers move symmetrically, keeping the gripped object centred on the wrist axis regardless of grip force.

Electronics & Firmware

The PIC18 runs firmware written in C (MicroC for PIC). Each 28BYJ-48 is driven by a ULN2003 driver. The TCS3200 sits at the front and outputs RGB as frequency ratios; the firmware classifies this data to determine the color of the cube a one-time calibration step.

Control is a pure sequential state machine: home → move to pick → grip → lift and scan → move to bin → release → home. An LCD shows the current state so you can follow the logic in real time.

Next Steps — Computer Vision

The TCS3200 works well in fixed lighting but is sensitive to ambient changes. The planned upgrade replaces it with a camera + OpenCV pipeline on a Raspberry Pi — HSV thresholding or a lightweight classifier for more robust detection, and the ability to pick from arbitrary positions rather than a fixed pick point.

This also opens the door to multi-object handling and dynamic bin assignment — turning the current demo into a general-purpose pick-and-place platform.
